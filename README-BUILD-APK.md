# KALAY-AWAN — Paano Gumawa ng .APK File

1. **Pinakamadali (Walang PC — GitHub Actions)**:
   - I-upload ang folder na ito sa isang libreng GitHub repository.
   - Pumunta sa tab na **Actions** -> **Build KALAY-AWAN Android APK** -> **Run workflow**.
   - Pagkatapos ng ~2 minuto, i-download ang compiled `.apk` file sa ilalim ng **Artifacts**.
2. **Gamit ang Android Studio**:
   - Buksan ang folder na ito sa Android Studio -> **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
